    How the calculation works

    The site converts all six entries into seconds in this fixed order: Arjun run, other run, Arjun beer 1, other beer 1, Arjun beer 2, other beer 2.

    It combines those six numbers with the fixed manager list, creates a SHA-256 hash, and uses the hash to run a deterministic Fisher–Yates shuffle.

    Identical times always produce the identical draft order. Changing any time changes the seed and therefore the draw.

    The calculator records durations only. It does not require rapid drinking; use whatever pace and rules the group agrees.
